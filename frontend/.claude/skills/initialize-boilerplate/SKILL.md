# Initialize frontend boilerplate only

1. Inspect the existing frontend directory before making changes.
2. Preserve user work and avoid overwriting existing files without permission.
3. Use the existing Next.js App Router, React, TypeScript, Tailwind, ESLint, and npm setup.
4. Create only missing organizational folders and necessary starter documentation/configuration.
5. Do not implement dashboards, authentication, forms, API clients, business logic, or other product features.
6. Do not add dependencies for future features.
7. Do not modify backend, database, or root-level monorepo files.
8. Run available lint/build commands and report exact results.
