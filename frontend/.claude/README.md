# Claude Code frontend configuration

This directory contains project-level Claude Code configuration for the TaskFlow frontend.

- `settings.json`: selected destructive-command deny rules.
- `rules/`: focused frontend coding and quality guidance.
- `commands/`: reusable slash commands.
- `agents/`: optional specialized review and test agents.
- `skills/`: repeatable frontend workflows.

These settings are guardrails, not a security sandbox. Review permission prompts and inspect commands before approving them.
