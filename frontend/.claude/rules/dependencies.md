# Frontend dependency rules

- Inspect `package.json` and the lockfile before using or adding a package.
- Prefer built-in Next.js, React, browser, and TypeScript capabilities when sufficient.
- Do not add dependencies for hypothetical future features.
- Ask before changing npm to another package manager or changing major framework versions.
- Keep lockfiles synchronized with package.json.
- Explain why each new dependency is necessary and how it is used.
