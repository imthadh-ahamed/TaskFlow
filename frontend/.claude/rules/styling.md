# Styling rules

- Use the existing Tailwind CSS configuration and conventions.
- Keep global styles limited to app-wide resets, tokens, and base styles.
- Prefer mobile-first responsive utilities and consistent spacing.
- Avoid introducing a second CSS framework or styling library without approval.
- Keep conditional class logic readable; extract a helper only when it improves clarity or reuse.
- Do not add animation, icon, or component libraries unless requested or justified by a concrete requirement.
