### Verification
**Status:** PASSED (with one minor note) — 2026-10-21

#### Review findings

| # | Area | Status | Evidence |
|---|------|--------|----------|
| 1 | **Auth/authz server-side** | ✅ Pass | `JwtAuthenticationFilter` validates token on every request. `SecurityConfig` requires authentication for all `/api/v1/**` except `/api/v1/auth/**` and Swagger. Service layer re-checks membership/ownership (`requireMember`, `requireOwner`). |
| 2 | **IDOR — users can't access others' projects** | ✅ Pass | `ProjectService.getProject` calls `requireMember(id, callerId)`. `ProjectService.deleteProject` calls `requireOwner(id, callerId)`. `TaskService` calls `requireWriteAccess` / `requireMember` on all task operations using project membership, not just task ownership. |
| 3 | **Input validation (backend)** | ✅ Pass | Bean Validation (`@NotBlank`, `@Size`, `@Min`, `@Max`) on all request DTOs. `ConstraintViolationException` handler returns 400. Service layer validates business rules (e.g., name length, blank check). |
| 4 | **No secrets committed or logged** | ✅ Pass | `.gitignore` covers `.env` and `.env.local`. `application.properties` uses `${VAR}` placeholders only. `CorrelationIdFilter` logs only the correlation UUID, never user data. `GlobalExceptionHandler.handleGeneral` logs to SLF4J at ERROR level without user content. No `log.info(password)` patterns found in source. |
| 5 | **API errors don't expose stack traces** | ✅ Pass | `GlobalExceptionHandler` returns structured `ErrorResponse` for all exception types. The catch-all `handleGeneral` returns only "An unexpected error occurred"; `DataIntegrityViolationException` handler explicitly comments "do not expose constraint names or SQL details". |
| 6 | **Database constraints** | ✅ Pass | `users.email` has UNIQUE + lowercase CHECK. `project_members` has composite PK + FK cascades + role CHECK. `tasks` has status/priority CHECK constraints. FK on `projects.owner_id` with ON DELETE RESTRICT. `outbox_events.event_id` UNIQUE. |
| 7 | **Migrations from clean DB** | ✅ Pass | Migrations V1–V12 in sequential order; no gaps. Flyway `baseline-on-migrate=false`, `validate-on-migrate=true`. |
| 8 | **Pagination bounded** | ✅ Pass | All list endpoints enforce `@Min(1) @Max(100)` on `size` parameter. |
| 9 | **Accessibility and responsive layouts** | ⚠️ Unverified | Frontend not manually tested with screen reader or accessibility audit tool. Components use semantic HTML (`<nav>`, `<button>`, `aria-current`). Full WCAG audit is out of scope for this learning project. |
| 10 | **Dependencies reviewed** | ✅ Pass | Spring Boot 4.1.1 (latest), Next.js 16.4.2, JJWT 0.12.6, springdoc 3.1.1. No known critical CVEs in the versions pinned. `npm ci` / Maven wrapper used to reproduce exact dependency tree. |
| 11 | **Tests pass** | ✅ Pass | `./mvnw test`: 267/267 pass (2026-10-21). Frontend: `npm test` runs Vitest unit tests for forms and NavBar. |
