#### Design notes

- Status values match the DB schema (`todo`, `in_progress`, `in_review`, `done`) — 4 statuses, not 3 as listed in the task spec suggestion. The migration is the authoritative contract.
- `Task` is a Java record (immutable); `transitionTo()` returns a new instance rather than mutating state.
- No persistence annotations anywhere in the domain package.
- Transition rules: TODO→IN_PROGRESS; IN_PROGRESS→IN_REVIEW or TODO; IN_REVIEW→DONE or IN_PROGRESS; DONE is terminal.
