### Verification

**Environment:** Windows 11, Java 21.0.10, Spring Boot 4.1.1, PostgreSQL 18.3 (local Windows service `postgresql-x64-18` on `localhost:5432`)

#### 1. Unit tests pass without a running database

```
cd backend
mvnw.cmd test
```

**Result:** `Tests run: 1, Failures: 0, Errors: 0, Skipped: 0` — BUILD SUCCESS.  
`DataSourceAutoConfiguration` and `FlywayAutoConfiguration` are excluded via `src/test/resources/application.properties`; the application context loads without a PostgreSQL connection.

#### Notes

- **Spring Boot 4.x module split:** `FlywayAutoConfiguration` moved from `spring-boot-autoconfigure` to the new `spring-boot-flyway` module. Adding only `flyway-core` leaves it absent from the conditions report entirely. Fix: use `spring-boot-starter-flyway` instead.
- **Test exclusion class names (Spring Boot 4.x):**
