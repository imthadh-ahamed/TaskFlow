### Verification

**Status:** Complete — all acceptance criteria verified.

#### Approach chosen

Maven Resources Plugin (`copy-flyway-migrations` execution) copies `database/migrations/*.sql` to `target/classes/db/migration/` at `process-resources` phase. Flyway reads from `classpath:db/migration` (Spring Boot default). No developer filesystem path configuration is required.

#### Key decisions

- **No filesystem path**: migrations are packaged into the classpath artifact, not referenced from an arbitrary local path.
- **Flyway not yet activated**: `flyway-core` and `spring-boot-starter-data-jpa` are not in `pom.xml`; the build step runs harmlessly until T4.x adds them.
- **`baseline-on-migrate=false`**: all databases start clean from V1; no implicit baseline.
- **Destructive resets are manual only**: `docker compose down -v` requires explicit operator action.
