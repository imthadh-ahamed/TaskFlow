### Verification

**Artifact created:** `scripts/acceptance-flow.sh`  
**Date:** 2026-10-21

**What the script covers (11 checks):**

1. Register owner and member accounts (POST /auth/register → 201)
2. Log in as owner (POST /auth/login → 200)
3. Verify authenticated session via `/me` (GET /auth/me → 200 + correct email)
4. Create a project (POST /projects → 201)
5. Add a member to the project (POST /projects/:id/members → 201)
6. Create a task (POST /projects/:id/tasks → 201)
7. Update task status to `in_progress` (PATCH /tasks/:id/status → 200)
8. Filter tasks by status (GET /projects/:id/tasks?status=in_progress → 200 + ≥1 result)
9. Verify persistence by re-fetching the task (GET /tasks/:id → 200 + correct status)
10. Confirm unauthenticated GET /projects → 401
11. Confirm duplicate email registration → 409

**Prerequisites:**
- Backend running at `http://localhost:8080`
- PostgreSQL running and Flyway migrations applied
- `jq` command-line JSON processor (`brew install jq` / `apt install jq` / `scoop install jq`)
- `curl` (included with Windows 10+, macOS, most Linux distros)

**How to run:**
```bash
bash scripts/acceptance-flow.sh
```
