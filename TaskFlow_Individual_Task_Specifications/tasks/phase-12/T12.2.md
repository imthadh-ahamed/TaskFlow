**Implementation notes recorded:**

- `postgresql` dependency scope changed from `runtime` to `compile` (default) — required because `JdbcProjectRepository`, `JdbcTaskRepository`, `JdbcMemberRepository`, and `JdbcCommentRepository` use `org.postgresql.util.PGobject` directly to set REFCURSOR parameters
- PostgreSQL JDBC 42.7.13 strict type checking requires REFCURSOR parameters to be passed as a `PGobject` with `type="refcursor"` via `PreparedStatement`; `CallableStatement.setString()` sends the param as `character varying`, causing "procedure does not exist"
- Cursors must be explicitly `CLOSE`d after `FETCH ALL` within the same transaction to avoid "cursor already exists" errors on repeated calls
