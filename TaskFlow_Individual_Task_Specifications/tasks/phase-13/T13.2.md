### Verification
**Status:** PASSED — 2026-10-21

**Changes made:**
- `backend/pom.xml` — added `spring-boot-starter-cache` and `spring-boot-starter-data-redis`
- `backend/src/main/java/com/taskflow/config/CacheConfig.java` — `@Configuration @EnableCaching`; tries Redis on startup; falls back to `NoOpCacheManager` on connection failure; TTL 30s; `GenericJackson2JsonRedisSerializer` for values, `StringRedisSerializer` for keys; cache name constant `PROJECTS_BY_USER = "projects-by-user"`
- `backend/src/main/java/com/taskflow/project/application/ProjectService.java` — `@Cacheable` on `listProjects` (key: `callerId:page:size`); `@CacheEvict(allEntries=true)` on `createProject`, `updateProject`, `deleteProject`
- `backend/src/main/resources/application.properties` — `spring.data.redis.host`, `spring.data.redis.port`, `spring.cache.redis.time-to-live=30s`
- `backend/.env.example` — `REDIS_HOST=localhost`, `REDIS_PORT=6379`
- `backend/src/test/java/com/taskflow/project/application/ProjectServiceCacheTest.java` — 4 cache unit tests using `ConcurrentMapCacheManager` (no Redis or DB required)
