**Notable design decisions:**
- `apiFetch` always uses `cache: "no-store"` so Server Component pages never serve stale project data.
- `ApiError` is a typed class carrying `status`, `code`, and `details[]`; field-level validation errors from the backend are displayed next to the relevant input using `aria-describedby` + `aria-invalid`.
- `usePathname()` in `NavBar` was blocking Next.js 16's "instant prerendering". Wrapping it in `<Suspense>` lets the static page shell render immediately and streams the active-link state in — routes now show as Partial Prerender (◐) rather than erroring.
- `ownerId` in `CreateProjectForm` is marked as a dev-stage field in the UI label, consistent with the backend note in `CreateProjectRequest`.
- The `[id]` detail page calls `notFound()` for 404 responses from the API, letting the nearest `not-found` boundary handle the error page rendering.
