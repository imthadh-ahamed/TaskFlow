**Notable design decisions:**
- `NavBar` is a Client Component (`"use client"`) solely to call `usePathname()` for active-link highlighting; everything else in the layout stays a Server Component.
- Placeholder routes are live (navigable) but marked in the nav with `aria-label "(coming soon)"` via `sr-only` span — sighted users see only the label; screen reader users get the full context.
- The `<main id="main-content">` anchor for the skip link moved from each individual page into `layout.tsx`, so the skip link destination is always present regardless of page content.
