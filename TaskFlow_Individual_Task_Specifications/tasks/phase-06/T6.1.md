## Task ID: T6.1

**Title:** Implement project endpoints  
**Owner component:** Backend

**Depends on:** T5.2 (inferred from the implementation-plan sequence; confirm if working out of sequence)

### Requirement
Provide versioned REST endpoints to create, list, view, update, and archive/delete projects according to the agreed deletion policy.

**Proposed API:**
- `POST /api/v1/projects`
- `GET /api/v1/projects`
- `GET /api/v1/projects/{projectId}`
- `PATCH /api/v1/projects/{projectId}`
- `DELETE /api/v1/projects/{projectId}` only if the deletion policy permits it

#### Design notes

- `DELETE /api/v1/projects/{id}` is implemented — the DB schema allows it (CASCADE to tasks/members).
- `ownerId` is accepted from the request body for this pre-auth stage; a TODO comment marks where it will be replaced by `SecurityContext` in the auth phase.
- PATCH null-field semantics: `null` = leave unchanged; `""` (empty string) = clear description to null.
- `@WebMvcTest` moved to `org.springframework.boot.webmvc.test.autoconfigure.WebMvcTest` in Spring Boot 4.x.
