### Requirement

**Proposed API:**
- `POST /api/v1/projects/{projectId}/tasks`
- `GET /api/v1/projects/{projectId}/tasks`
- `GET /api/v1/tasks/{taskId}`
- `PATCH /api/v1/tasks/{taskId}`

**Notable design decisions:**
- `UpdateTaskRequest.clearAssignee` is `Boolean` (not `boolean`) so Jackson maps absent JSON field to `null` (treated as false), avoiding `HttpMessageNotReadableException` on partial PATCH bodies.
- `TaskService.updateStatus` calls `existing.transitionTo(req.status())` for domain validation before delegating to the repository, so invalid transitions throw before any DB write.
- `TaskService` depends on `JdbcProjectRepository` directly (no cross-service call) to validate project existence on create/list without introducing a circular dependency.
